RESILIENCEPILOT SDV · DAY 1 · READ-ONLY REPORT

HTTP 200 is not the same as healthy data.

The Eclipse SDV Fleet Management rFMS API kept answering HTTP 200, with a fresh-looking receivedDateTime, while the vehicle's own createdDateTime stopped advancing. ResiliencePilot detects that from the data, injects it on purpose under a safety controller, and verifies recovery.
